# Yassine Nemri · Portfolio

Vite + vanilla JS, GSAP ScrollTrigger and Lenis.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

- Palette (three colors only): Ink `#0C0E13`, Ivory `#F2ECE3`, Ember `#FF5B35`. Defined in `src/style.css`.
- Projects: `src/projects.js`. Screenshots: `public/shots/*.webp`.
- `scripts/shoot.mjs` captures screenshots of a running app with headless Chrome; `scripts/frames.mjs` grabs frames from a demo video.
- The Rakcha and Lidara screenshots show demo data from sandbox copies, not the real vault or inbox.
